# zero-tolerance-review

Скилл для Claude Code: рецензия с нулевой терпимостью. Разбирает курсовую, диплом, статью, проект, презентацию, бизнес-идею или концепт игры так, как это сделает самый придирчивый оппонент на защите.

На выходе:
- вердикт рецензента: не допускать / на доработку / допустить с замечаниями;
- слабые места по тяжести (критично, серьёзно, мелочи), у каждого место в работе и последствие;
- вопросы, которые зададут на защите;
- план доработки по порядку, с учётом срока, если он назван.

Похвал и смягчений нет. Выдуманных проблем тоже: что нельзя проверить, помечается «проверь сам». Цифры и статистику из работы скилл пересчитывает сам.

## Установка

```bash
git clone https://github.com/Vanessaaas/zero-tolerance-review.git ~/.claude/skills/zero-tolerance-review
```

Перезапустите Claude Code.

## Использование

```
/zero-tolerance-review
```

Или обычной фразой с приложенной работой: «разнеси мою курсовую», «прожарь идею», «побудь оппонентом на защите», «найди все косяки».

Для учебных работ пришлите методичку кафедры: скилл ставит её выше типовых требований (ГОСТ 7.32-2017, ГОСТ Р 7.0.100-2018).

## Состав

- `SKILL.md`: процесс, правила, формат ответа, примеры.
- `references/lenses.md`: чек-листы по типам работ.
- `evals/`: тестовая курсовая с заложенными ошибками для проверки скилла.
